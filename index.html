MD Reader

零依赖、纯本地的 Markdown 阅读器。双击 .md 文件即可打开，所有渲染在本地完成，不联网、不上传。支持 macOS 与 Windows。

macOS 13.0+ Apple Silicon + Intel 通用 Windows 10 / 11 v1.1 · 离线可用
⬇ 下载 macOS 版 v1.0 · DMG · 通用二进制 ⬇ 下载 Windows 版 v1.1 · ZIP · 免安装
macOS：打开 MDReader.dmg 拖入「应用程序」。Windows：解压后运行 install.bat（管理员）或 associate.bat 一键关联 .md。
📂

双击即开

关联 .md / .markdown / .mdown / .mkd，设为默认程序，点击文件直接阅读。

🈶

全中文界面

菜单与右键菜单均已中文化，原生 macOS 体验。

⚡

离线渲染

marked.js 已内联进页面，零外部依赖，断网也能秒开。

🔍

目录 + 搜索

侧边目录导航，⌘/Ctrl+K 全文搜索，深色 / 浅色主题一键切换。

🕘

最近打开

自动记录最近文件，拖拽打开、一键在 Finder 定位源文件。

MIT 许可证，源码公开，可自行 bash build.sh 重新构建。

Windows 版说明

  1. Windows 版用「 PowerShell 本地服务 + 系统默认浏览器 」实现，无需安装、无需联网下载任何组件，解压即用。
  2. 首次右键 install.bat → 以管理员身份运行，即可把 .md 关联成本程序。
  3. 想要内嵌窗口、不弹浏览器的真正编译型 .exe（基于 Edge WebView2）？详见压缩包内 neutralino-src/ 与 README-Windows.md 的进阶教程（需在可访问 GitHub 的机器上编译）。
